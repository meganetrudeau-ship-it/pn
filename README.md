# Site web Pure Nature Agro-Solutions

Ce dossier contient un site web one-page prêt à publier sur GitHub Pages pour le domaine : pnagrosolutions.com.

## Fichiers inclus

- `index.html` : structure du site
- `style.css` : design complet et responsive
- `script.js` : menu mobile et année automatique
- `CNAME` : domaine personnalisé pour GitHub Pages
- `assets/` : logo et images optimisées

## Mise en ligne avec GitHub Pages

1. Créer un repository GitHub, par exemple `pnagrosolutions-site`.
2. Ajouter tous les fichiers du dossier à la racine du repository.
3. Aller dans **Settings > Pages**.
4. Dans **Build and deployment**, choisir :
   - Source : Deploy from a branch
   - Branch : main
   - Folder : /root
5. Attendre que GitHub génère l'adresse temporaire du site.
6. Dans **Custom domain**, inscrire : `pnagrosolutions.com`.
7. Configurer les DNS chez le fournisseur du nom de domaine.
8. Une fois le domaine actif, activer **Enforce HTTPS**.

## À personnaliser au besoin

- Le lien LinkedIn peut être ajouté dans la section Contact.
- Les textes peuvent être ajustés directement dans `index.html`.
- Les couleurs principales sont dans `style.css`, dans la section `:root`.
